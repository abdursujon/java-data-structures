# Java Data Structures 

This project is a practical guide to help beginner learn data structures in java. 
It covers all necessary java provided data structures alongside custom data structures 
for example how to build circular array queue, how array list internally built and more. 

# Structure how the repo should be used to learn java data structure in sequence 

1. Arrays 
- Default array 
- Matrix array 
- Arrays (Java array helper class)

2. String 
- String class methods 
- StringBuilder 

3. Interfaces 
- Collection 

4. List 
- ArrayList 
- LinkedList

5. Set 
- HashSet 
- LinkedHashSet 
- TreeSet 

6. Map 
- HashMap 
- LinkedHashMap 
- TreeMap 

7. Queue 
- ArrayDeque 
- PriorityQueue 

8. Stack 
- Stack 

9. DS Helper Class 
- Collections 

10. Concurrency 
- ArrayBlockingQueue 
- LinkedBlockingQueue

## Getting Started

Clone the repo:
```bash
  git clone https://github.com/abdursujon/java-data-structures.git
```

Open it in your IDE or \
Edit it terminal  
```bash
  cd ../java-data-structures/src/java_provided_ds/list
  nano ArrayListExample.java
```

## Example Run 

- Use IDE run button or cd into package you would like to run and run commands like below.

```bash
cd src/java_provided_ds/list
java ArrayListExample.java
```
